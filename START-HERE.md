# Local MemeBox review

Download review/memebox-local-2026-10-14 as a GitHub ZIP and extract the complete archive. Nothing on this branch is deployed and real checkout stays closed.

1. Run **review/Start-MemeBox-Music.cmd** on Windows and keep the console open. This starts the local music/meme player; no Node installation is needed. On macOS/Linux run `python3 review/start-music.py`.
2. Open **chrome://extensions**, enable Developer mode and load **review/extension** unpacked. Disable the Web Store copy while testing. This review unlocks paid features locally; never publish it.
3. When updating, reload the extension and the meeting tab. Extract to a fresh folder if old and new files are getting mixed. Your existing private uploads live in extension storage, so using the same extension folder path preserves that copy's identity.
4. Open Music or Video memes from the call panel. It opens the web player directly. The review includes five supplied playlist references, thirteen short background tunes, 27 clean meme candidates and six After Dark candidates. Five reported broken links are excluded. Provider restrictions can still affect individual videos.
5. To send playlist / video meme audio to the call, open the player, then choose **Everyone in call** in the call panel. Choose **the player browser tab**, enable **Share tab audio**, then confirm. The same connection carries every song and meme you play in that tab. The **Share playlist / meme audio** button can reconnect it. You can also start sharing from inside the player. Only audio reaches the meeting microphone; the selected screen video is not forwarded. Keep the meeting mic unmuted. **Only me** disconnects sharing.
6. In Options choose a picture, inspect its preview, optionally add a caption and choose whether to read it aloud, then press Add. Checked **Read caption aloud** speaks the caption or your explicit **Pronounce as** text. Unchecked stays silent. An empty caption and pronunciation never speak a filename or library title. Saved pictures show a thumbnail and voice status. Turn on Camera captions to show the picture to other callers. Close/Escape/Stop all removes it.
7. Characters work independently of camera lights. Hold supported hand poses beside your face for about a second; High sensitivity checks hands more often. Playground previews fourteen companions, nine outfits and 28 filters.

Plans contains current permanent filter/costume/character prices and pass-only Max exclusives. Payments remain closed. Shared catalog edits belong in the admin; users' own uploaded files stay on their device. No shared playlist editing is exposed to consumers.
