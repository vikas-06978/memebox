# Global meme audio pack: source and rights research

This is the working blueprint for the owner-supplied year list. It is not a licence. “Likely source” must be replaced by a verified original URL or written owner confirmation before a downloaded recording is marked Live. Audio can be attached later using the suggested file slug.

Status meanings:

- **Contact**: a likely creator or rights holder is known; request redistribution permission.
- **Research**: the supplied name is ambiguous or the original uploader is not verified.
- **Licensed source only**: the recording comes from a film, show, game, advert or song; use only with a licence from its rights holder.
- **Policy review**: review language, harassment, sexual content or featured minors before store release.

## Audio handoff

When audio is added later, name it using the suggested slug where possible. In Admin → Packs, attach it to a Draft pack and fill:

1. **Credit**: verified creator/performer name users should see.
2. **Source**: original post or official rights/licence page, not a random compilation.
3. **Licence**: written permission terms or a compatible published licence.
4. **Strong language**: mark explicit items so they remain hidden by default.
5. **I may share this**: tick only after the licence evidence is retained.
