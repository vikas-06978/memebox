Questions

Les autres personnes de l'appel ont-elles besoin de MemeBox ?

Non. Le mème passe par votre micro, donc elles l'entendent comme votre voix.

Ça marche dans l'appli de bureau Zoom ou Teams ?

Non, seulement dans les versions navigateur. Ouvrez le lien de votre réunion dans Chrome ou Edge.

Pourquoi personne n'entend les mèmes ?

Vérifiez que votre micro n'est pas coupé dans l'appel. Les mèmes sont muets quand votre micro est coupé. Si vous venez d'installer ou de mettre à jour MemeBox, rechargez une fois l'onglet de l'appel.

Comment payer Pro ?

Avec n'importe quelle appli UPI (GPay, PhonePe, Paytm, BHIM). Scannez le QR code sur la page d'achat, saisissez l'identifiant de transaction, et votre clé apparaît dès que le paiement est confirmé.

Ma voix est-elle enregistrée ?

Jamais. MemeBox mixe seulement le son dans l'onglet de votre navigateur. Rien n'est sauvegardé ni envoyé.
